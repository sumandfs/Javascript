# JavaScript Learning & Practice

A hands-on repository for strengthening JavaScript fundamentals through small, runnable examples. The code is organized by topic and is intended for practice and revision.

## Repository structure

```text
Javascript/
└── 01_basics/
    ├── 01_variables.js
    ├── 02_datatypes.js
    ├── 03_conversionOperation.js
    ├── 04_comparison.js
    ├── 05_strings.js
    ├── datatype-summary.js
    └── test.js
```

## Topics currently covered

| File | Concepts |
|---|---|
| `01_variables.js` | Variable declarations |
| `02_datatypes.js` | JavaScript data types |
| `03_conversionOperation.js` | Type conversion and operations |
| `04_comparison.js` | Comparison operators |
| `05_strings.js` | String operations and methods |
| `datatype-summary.js` | Data-type revision examples |

## Run an example

1. Install Node.js.
2. Clone this repository.
3. Open a terminal in the repository folder.
4. Run a file with Node.js:

```bash
node 01_basics/01_variables.js
```

To try another topic, replace the filename with the example you want to run.

## Learning approach

- Read the example and its comments.
- Run the file and observe the output.
- Change the input values and test the behavior.
- Write a small variation without looking at the original code.
